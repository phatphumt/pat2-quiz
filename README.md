# Exam Workspace — กระดาษคำตอบ + Annotation

เว็บแอปสำหรับอ่านโจทย์จาก PDF ทำข้อสอบแบบ OMR และจดโน้ตบนหน้าเอกสาร เขียนด้วย **Vanilla HTML/CSS/JS** ไม่ต้อง build ไม่ต้องติดตั้ง dependency (ใช้ PDF.js แบบ vendor ไว้ในโปรเจกต์) มาพร้อมไฟล์ตัวอย่าง PAT2 ชีววิทยา (`pdf/source.pdf` + `pages/`) แต่ใช้กับ PDF/เฉลยชุดอื่นได้

## เปิดใช้งาน
- ดับเบิลคลิก `index.html` ได้เลย (รองรับ `file://`)
- หรือเสิร์ฟผ่านเซิร์ฟเวอร์ local (แนะนำถ้าเจอปัญหา worker):
  ```
  cd C:\Users\Phatphum\pat2-quiz
  python -m http.server 8000
  ```
  แล้วเปิด http://localhost:8000

## ฟีเจอร์
### ข้อสอบ + กระดาษคำตอบ
- แสดงหน้าโจทย์จาก `pages/page-XX.png` เลื่อน/ซูม/กระโดดไปหน้าใดก็ได้ และมีปุ่ม **เปิด PDF** สำหรับเปิดเอกสารปัจจุบัน
- **แก้ไขชื่อชุดข้อสอบและคำอธิบาย/วิชา** ได้จากปุ่มดินสอในหัวแอป → ชื่อจะแสดงบนหัวแอปและกระดาษคำตอบ
- กระดาษคำตอบ OMR ปรับจำนวนข้อตามเฉลยที่โหลด (ไฟล์ตัวอย่างเริ่มต้น 29 ข้อ) และปรับจำนวนคอลัมน์ตามความกว้างจอ
- แสดงความคืบหน้าการตอบ, ปุ่ม **ข้อถัดไปที่ยังว่าง**, กด ○1–5 ซ้ำเพื่อล้างคำตอบ
- **ตรวจคำตอบ** ได้แม้ตอบไม่ครบ → คะแนน / ถูก / ผิด / ไม่ตอบ, ไฮไลต์รายข้อ, วงแหวนสีเขียว = เฉลย, และเลื่อนไปข้อที่ต้องดูก่อน
- แถบสถานะ/ปุ่มตรวจคำตอบตรึงไว้ด้านล่างของกระดาษคำตอบ จึงกดตรวจได้ตลอดเวลา (เดสก์ท็อปและมือถือ)
- บันทึกคำตอบ ชื่อ วันที่ และลายเส้นไว้ใน `localStorage` อัตโนมัติ

### Annotation + Pen Tablet
- เครื่องมือ: **มือ / ปากกา / ไฮไลต์ / ยางลบ (ลบทั้งเส้น)**
- สีแยกตามเครื่องมือ (ปากกาและไฮไลต์คนละสี) 6 สี: แดง น้ำเงิน ดำ เขียว เหลืองส้ม ม่วง
- ขนาดแยกตามเครื่องมือ: ปากกา 1–12 px, ไฮไลต์ 6–30 px, ยางลบ 6–40 px (วงแหวนบอกขนาดยางลบ)
- **Undo/Redo แบบ global ต่อเอกสาร** ครอบคลุมการวาด ลบ ล้างหน้า และล้างทั้งหมด พร้อม disabled state
- รองรับ **ปากกา/แท็บเล็ต**: แรงกด (pressure) ปรับความหนาเส้น, `getCoalescedEvents()` เก็บจุดความถี่สูง, ปลายยางลบของปากกา (eraser tip / ปุ่มลำตัว)
- **Palm rejection**: นิ้วไม่วาดเมื่อใช้ปากกาอยู่; ค่าเริ่มต้นนิ้ว = เลื่อนหน้า (เปิด **"วาดด้วยนิ้ว"** ถ้าไม่มีปากกา)
- ลายเส้นผูกกับ "เอกสาร" (ไฟล์ตัวอย่างหรือไฟล์ที่อัปโหลด) → สลับไฟล์แล้วไม่ปนกัน

### การนำทาง / ประสิทธิภาพ
- ปุ่มหน้าก่อน–หน้า, ช่องกรอกเลขหน้า, `PgUp` / `PgDn`
- ซูมเข้า/ออกเป็นขั้น, ปุ่ม **พอดีความกว้าง**, จำตำแหน่งหน้าและระดับซูมล่าสุดต่อเอกสาร
- PDF ที่อัปโหลดจะ **เรนเดอร์เฉพาะหน้าที่ใกล้หน้าจอ** (IntersectionObserver) และเรนเดอร์ความละเอียดสูงขึ้นให้อัตโนมัติเมื่อซูมเข้า (debounced)

### อัปโหลด PDF
- ปุ่ม **อัปโหลด PDF** หรือลากไฟล์มาวางบน panel ข้อสอบ
- จำนวนหน้าและอัตราส่วนหน้าปรับอัตโนมัติ, รองรับ PDF หน้าที่มีขนาดต่างกัน
- ไฟล์ PDF เก็บในหน่วยความจำเท่านั้น (ปิดแท็บแล้วต้องอัปใหม่) แต่ลายเส้นของไฟล์เดิมจะกลับมาเมื่ออัปไฟล์เดียวกัน (อ้างอิงชื่อไฟล์ + ขนาด + lastModified)
- แสดงข้อความผิดพลาดที่อ่านได้เมื่อไฟล์เสียหรือมีการใส่รหัสผ่าน และคงเอกสารเดิมไว้
- ปุ่ม **ใช้ไฟล์ตัวอย่าง** กลับไปใช้ `pdf/source.pdf` (หน้าภาพ `pages/`)
- หมายเหตุ: เมื่อเปิดผ่าน `file://` เบราว์เซอร์จะไม่ให้สร้าง Worker จากไฟล์ local แอปจึงโหลด `vendor/pdfjs/pdf.worker.min.js` เข้าหน้าและใช้ fake worker (main thread) ของ PDF.js แทน; ถ้าเปิดผ่าน HTTP จะใช้ Worker ปกติ

### อัปโหลดเฉลย (JSON)
กด **อัปโหลดเฉลย** ในกระดาษคำตอบ รองรับรูปแบบ:
```json
[1, 1, 3, 4, 3]
```
```json
{ "1": 1, "2": 1, "3": 3 }
```
```json
{ "answers": [1, 1, 3, 4, 3] }
```
```json
{ "answers": { "1": 1, "2": 1, "3": 3 } }
```
- ค่าต้องเป็น 1–5; จำนวนข้อในกระดาษคำตอบจะปรับตามจำนวนในไฟล์
- คำตอบที่อยู่นอกช่วงของเฉลยใหม่จะถูกล้างอย่างปลอดภัย
- ปุ่ม **คืนค่าเฉลยเริ่มต้น** กลับไปใช้เฉลยตัวอย่าง (29 ข้อ)

## คีย์ลัด
| ปุ่ม | การทำงาน |
|---|---|
| `P` / `H` / `E` / `V` | ปากกา / ไฮไลต์ / ยางลบ / มือ |
| `Esc` | กลับไปเครื่องมือมือ |
| `[` `]` | ลด / เพิ่มขนาดเครื่องมือ |
| `PgUp` / `PgDn` | หน้าก่อน / หน้าถัดไป |
| `Ctrl` + `+` / `-` | ซูมเข้า / ออก |
| `Ctrl+Z` | เลิกทำ (global) |
| `Ctrl+Shift+Z` หรือ `Ctrl+Y` | ทำซ้ำ |
| `?` | เปิดหน้าต่างคีย์ลัด |

## ที่เก็บข้อมูล (`localStorage`)
| Key | เก็บอะไร |
|---|---|
| `pat2-quiz-exam-v1` | ชื่อชุดข้อสอบและคำอธิบาย/วิชา |
| `pat2-quiz-v2` | คำตอบ, ชื่อ, วันที่ |
| `pat2-quiz-key-v1` | เฉลยที่อัปโหลด |
| `pat2-quiz-ink-v3` | ลายเส้นทุกเอกสาร (อ่าน/ย้ายจาก `pat2-quiz-ink-v2` อัตโนมัติ) |
| `pat2-quiz-prefs-v2` | เครื่องมือ, สีปากกา/ไฮไลต์, ขนาด, ตัวเลือกวาดด้วยนิ้ว (อ่าน/ย้ายจาก `pat2-quiz-prefs-v1`) |
| `pat2-quiz-pos-v1` | หน้าล่าสุด, ตำแหน่ง scroll, โหมดพอดี/ซูม ของแต่ละเอกสาร |

> ชื่อ key ยังใช้ namespace `pat2-quiz-*` เพื่อรักษาข้อมูลเดิมของผู้ใช้ แม้ UI จะเป็น workspace ทั่วไปแล้ว

> หากพื้นที่ `localStorage` เต็ม แอปจะแจ้งเตือนและยังใช้งานต่อได้ แต่ลายเส้นใหม่อาจไม่ถูกบันทึก

## โครงสร้าง
- `index.html`, `styles.css`, `app.js` — UI / กระดาษคำตอบ / จัดการเอกสาร / navigation
- `ink.js` — เอนจินวาด (pointer events, pressure, eraser, global undo/redo, autosave)
- `pdf-loader.js` — โหลด/เรนเดอร์ PDF ด้วย PDF.js (รวม lazy page info/render)
- `data/default-key.js` — เฉลยตัวอย่างเริ่มต้น 1–29
- `vendor/pdfjs/` — PDF.js + `pdf.worker.min.js`
- `pages/` — ภาพหน้าตัวอย่าง, `pdf/source.pdf` — PDF ตัวอย่าง, `favicon.svg` — ไอคอนแอป
